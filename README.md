# 💼 Hoja de Vida Web & Visual (Responsive)

Versión interactiva y de presentación visual del currículum profesional de **Juan Diego Rodríguez Yanquen**, diseñada para entrevistas directas, entrega física o despliegue como portafolio web personal.

---

## ✨ Características Principales

* **Diseño en dos columnas (CSS Grid):**
  * **Barra lateral izquierda (`#1e293b`):** Fotografía de perfil circular, datos de contacto con enlaces interactivos, competencias blandas e idiomas.
  * **Área principal derecha:** Resumen profesional, experiencia detallada en el proyecto full-stack **ALIMOP**, educación y matriz de habilidades técnicas organizadas en tarjetas.
* **Completamente adaptable (*Responsive Design*):**
  * Breakpoint en `820px` que reorganiza el contenido a una sola columna para teléfonos y tabletas.
* **Optimizado para Impresión / Exportación a PDF:**
  * Estilos `@media print` calibrados al milímetro para comprimir armoniosamente toda la información en **exactamente 1 página** tamaño Carta / A4.
* **Teoría del Color y Accesibilidad:**
  * Paleta balanceada en tonos azul oscuro (`#1e293b`), acento azul claro (`#38bdf8`) y fondos claros (`#f8fafc` / `#ffffff`) que aseguran alto contraste y descanso visual.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica enriquecida con metadatos.
* **CSS3 Moderno:** CSS Grid, Flexbox, Variables, Media Queries y estilos `@media print`.

## 🌐 Despliegue en GitHub Pages (Opcional)

Puedes publicar este currículum en internet de forma gratuita con **GitHub Pages**:
1. Sube este repositorio a tu cuenta de GitHub.
2. Ve a **Settings** > **Pages** en tu repositorio.
3. En la sección **Branch**, selecciona la rama `main` (o `master`) y la carpeta `/ (root)`.
4. Haz clic en **Save**. En unos minutos tu currículum estará en vivo en una URL pública (ejemplo: `https://juandirodriguezy.github.io/tu-repo/`).

---

## 🖨️ Cómo Exportar a PDF (1 Página)

1. Abre el archivo `index.html` en tu navegador web.
2. Pulsa `Ctrl + P` (en Windows) o `Cmd + P` (en Mac).
3. Configuración recomendada:
   * **Destino:** Guardar como PDF
   * **Diseño:** Vertical
   * **Márgenes:** Predeterminados o Ninguno
   * **Opciones:** Activar **Gráficos de fondo** (para que se imprima el color de la barra lateral)
   * Desactivar *Encabezados y pies de página*.
4. Haz clic en **Guardar**.
